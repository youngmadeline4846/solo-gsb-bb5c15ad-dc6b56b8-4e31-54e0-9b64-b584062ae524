# 盲文标签排版台（Braille Label Studio）

输入英文标签文字与板材宽/高、点距、行距，系统按**六点一级盲文**转换并排版；支持**多标签拼版**（每行一条标签、0/90° 旋转、行级装箱到整张板材）；另提供**压印质检**模式，将实测凸点 CSV 与最近一次成功排版（单标签或拼版）的设计点逐一比对；以及**压印路径**模式，对最近一次成功排版/拼版的凸点生成压印机逐点作业顺序：

- 大写字母前自动添加大写前缀 `⠠`（点 6）
- 连续数字段只在段首添加一个数字前缀 `⠼`（点 3-4-5-6）
- **单标签排版**：依据转换后的盲文单元**整词换行**，词间空一个空白单元
- 任何单词放不下、或总行数超出板材容量时，**明确指出原因，绝不裁切**
- **多标签拼版**：多行标签逐条复用同一套盲文转换，每条作为**不可拆分矩形**做带边距的二维行级装箱，允许 **0°/90° 旋转**，按**剩余面积最小 → y → x → 0°** 稳定择优；任一标签放不下时逐条给出原因且不输出部分版面
- 页面实时预览带毫米（mm）坐标的凸点 SVG（拼版同时画出**每个标签的边界与索引/旋转角**），并可下载 **SVG** 与**排版 JSON**（含标签索引与旋转角）
- **压印质检**：粘贴实测凸点 CSV、设置校准旋转角/偏移/合格公差/关联半径，叠加 SVG 区分四类结果并下载质检报告 CSV；质检页可一键选择**最近一次成功的单标签排版或多标签拼版**作为基准——拼版基准显示标签数量及各标签索引/旋转角，请求直接使用拼版返回的顶层 `dots`（保留 `label`、`rotation` 元数据），叠加图与 CSV 报告会标注每个结果所属标签；尚无成功拼版时拼版基准按钮禁用并提示先完成拼版
- **自动校准**：实测点顺序无须对应，设置 X/Y 最大校准量后一键估算全局平移并写回偏移、自动重跑；另可设置**最大旋转角与角度步长**启用**小角度刚体校准**（围绕板材中心的旋转 × 平移联合搜索）；正确处理缺失点与多余点，不使用质心差
- **压印路径**：单标签排版或拼版成功后，以当前 `dots` 为输入、从用户指定起点（**压印机坐标**或**凸点原序号**二选一）出发，先用**最近邻**生成路线，再执行**最多 20 轮 2-opt**（每轮按反转段起止下标顺序接受**首个严格缩短**的反转）；同距离按**标签索引 → 点坐标 (x,y) → 原序号**稳定决胜，相同输入结果一致且**每个凸点恰好访问一次**；页面显示**优化前/后空移总长、节省长度与比例**并叠加**带步骤序号与行进方向的路径预览**，可下载含 `step,label,x_mm,y_mm,travel_mm` 的作业 CSV（及路径 SVG）；**超过 2000 个点或参数非法时明确报错，绝不输出部分路径**

## 一条命令启动（Docker Compose）

```bash
docker compose up --build
```

Compose 会在构建镜像时自动完成依赖安装与初始化。启动后在浏览器访问：

**http://localhost:3000** （容器内外端口均为 `3000`）

页面顶部四个页签即为入口：

- **排版模式**（`http://localhost:3000/`，默认页签）：单标签盲文转换、整词换行排版与 SVG/JSON 下载；
- **多标签拼版**：点击顶部「**多标签拼版**」页签，每行输入一条英文标签，整板预览标签边界与凸点，下载含标签索引/旋转角的 SVG/JSON；
- **压印质检**：点击顶部「**压印质检**」页签进入，通过左侧「单标签排版基准 / 最近拼版基准」按钮选择当前会话中最近一次成功的单标签排版或多标签拼版作为质检基准。
- **压印路径**：点击顶部「**压印路径**」页签进入，通过左侧「单标签排版基准 / 最近拼版基准」按钮选择当前会话中最近一次成功结果的凸点作为路径输入，设置起点后生成逐点作业顺序、叠加预览并下载作业 CSV。

停止：`docker compose down`

## 使用说明（排版模式）

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| 标签文字 | 英文标签（A–Z、a–z、0–9 及常用标点，≤500 字符） | `EXIT Door 2` |
| 板材宽度 / 高度 | 标签板材幅面，单位 mm | 100 × 50 |
| 点距 | 单元内相邻凸点中心距，单位 mm | 2.5（标准盲文） |
| 行距 | 相邻两行顶行点的中心距，单位 mm | 10（标准盲文） |
| 边距（高级） | 板材四周边距，单位 mm | 5 |
| 字距（高级） | 相邻单元净间距，留空 = 1.4×点距（标准 → 6mm 单元pitch） | 自动 |
| 凸点直径（高级） | 留空 = 0.6×点距（标准 ≈1.5mm） | 自动 |

放不下时的报错示例：

- `单词 “EXIT” 转换后占 6 个盲文单元（含大写/数字前缀），超过每行最多 4 个单元……`
- `整词换行后共需 5 行，板材有效高度仅容纳 4 行……`

## 多标签拼版模式

在「多标签拼版」页签的文本框中**每行输入一条英文标签**（空行自动跳过并计入“跳过空行”），所有标签共享同一组板材 / 点距 / 行距 / 边距 / 标签间距参数。

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| 多条标签 | 每行一条英文标签（A–Z、a–z、0–9 及常用标点）；单次 ≤100 条、每条 ≤500 字符 | 5 条示例 |
| 板材宽度 / 高度 | 整张拼板幅面，单位 mm | 120 × 80 |
| 点距 / 行距 | 与单标签排版相同：单元内点中心距 / 相邻行中心距 | 2.5 / 10 |
| 板材边距（高级） | 板材四周内边距，所有标签矩形必须落在该有效幅面内 | 5 |
| 标签间距（高级） | 相邻标签矩形之间的水平 / 竖直净间距 | 5 |
| 字距 / 凸点直径（高级） | 同单标签排版，留空自动 | 自动 |

算法说明：

1. **逐条复用单标签盲文转换**：每条标签按单行生成盲文，得到一个**不可拆分矩形**（宽 = 单行单元占宽，高 = 2×点距）；
2. **带边距的二维行级（shelf）装箱**：从上到下开“行”，行内从左到右摆放，标签间留标签间距；
3. 每个标签枚举 **0° 与 90°（顺时针）** 两种朝向，候选位置包括“每个现有行内剩余处”与“新开一行”，按
   **① 放入后已装区域剩余面积最小**（标签面积在旋转下不变，等价于已装包围盒面积最小）→ **② y 最小 → ③ 包围盒左缘 x 最小 → ④ 优先 0° → ⑤ 行序号最小**
   选出唯一位置，结果完全确定、可重复；
4. **任一标签**含不支持字符、**0° 与 90° 都超出板材有效幅面**、或装箱阶段**在任何行（含新开行）都放不下**时，接口返回**逐条**错误（标签序号 + 具体尺寸/幅面原因），并且 `ok=false`、`svg/dots/labels` 全为空——**绝不输出部分版面**。

预览与下载：

- 整板 SVG 画出板材、边距参考线、**每个标签的边界矩形（蓝色 0° / 橙色 90°）、索引与 `⟳90°` 标记、`<title>` 悬停原文**及全部凸点；每组带 `data-label-index` 与 `data-rotation`；
- **下载拼版 JSON**：`labels[]` 逐条给出索引、源行号、原文、盲文 Unicode、旋转角（0/90）、锚点与包围盒 `bounds{x,y,width,height}` 及该标签全局凸点；顶层 `dots[]` 为全部凸点展平（含 `label` 与 `rotation` 字段），**字段结构是单标签 `dots{x,y,r}` 的超集，可直接作为 `/api/qc` 的设计点基准**；
- 统计含标签数、旋转数、已装区域 `packWidth × packHeight`、标签总面积与**剩余面积**。

放不下时的报错示例：

- `标签 #3「…」单行盲文尺寸为 176.5 × 5 mm（宽 × 高），即使旋转 90°（5 × 176.5 mm）也超出板材有效幅面 110 × 70 mm……`
- `标签 #4「…」（尺寸 86.5 × 5 mm，含 0°/90° 两种朝向）在当前板材有效幅面 8 × 90 mm 与已排 1 个标签之后已无空位可放……`

## 压印质检模式

进入「压印质检」页签后，先用左侧两个基准按钮选择基准来源：

- **单标签排版基准**：最近一次成功的单标签排版（左侧绿色基准条显示基准标签文字、设计点数与排版时间；排版失败不会覆盖基准）；
- **最近拼版基准**：最近一次成功的多标签拼版，**一键选用**即可——基准条显示标签数量、旋转 90° 条数、设计点总数，并逐个列出标签的**索引 / 旋转角**（`#n` / `#n ⟳90°`，悬停显示原文）；质检请求直接发送拼版返回的顶层 `dots`（每个点保留 `label`、`rotation` 元数据）。**尚无成功拼版时该按钮禁用**（悬浮提示先完成拼版），基准条黄色提示先去拼版；拼版失败不会覆盖已有拼版基准。

切换基准会清空上一次质检结果并（在已粘贴 CSV 时）自动按新基准重跑；切回单标签排版时仍可继续使用单标签基准，原有 API 参数与调用方式完全兼容。

| 输入 | 含义 |
| --- | --- |
| 实测凸点 CSV | 每行一个点，两列 `x_mm,y_mm`（mm）；首行可为 `x_mm,y_mm` 表头（可省略），允许空行；**点的顺序无须与设计点对应** |
| X / Y 校准偏移 | 对旋转后的实测坐标再整体平移：比较坐标 = R(旋转角)·(实测−板材中心) + 板材中心 + (offsetX, offsetY) |
| 校准旋转角 | 实测点围绕板材中心（板材幅面之半）的刚体旋转角（度，逆时针为正），默认 0；由「一键自动校准」自动写回 |
| 合格公差 | 配对欧氏距离 ≤ 公差判为「合格」，否则为「偏移超差」 |
| 最大关联半径 | 只有设计点与刚体校准后实测点距离 ≤ 半径时才允许配对 |
| X / Y 最大校准量 | 「一键自动校准」的候选限幅：仅保留 \|dx\|、\|dy\| 均不超限的候选平移（默认 2 mm） |
| 最大旋转角 / 角度步长 | 小角度刚体搜索范围与采样步长（度）：角度在 `[-最大旋转角, 最大旋转角]` 内按步长枚举（含 0°）。最大旋转角留 `0` 时只估平移（与旧版一致）；最大旋转角上限 15° |

比较算法：在关联半径构成的二分图上做**一对一最优匹配**，优先级依次为 ① 匹配对数最多 → ② 总欧氏距离最小 → ③ 再相同则按设计点序号与 CSV 行号稳定决胜（每个实测点最多匹配一个设计点，绝不重复配对）。未配对的设计点记为**缺失**，未配对的实测点记为**多余**。

### 一键自动校准（全局平移 / 小角度刚体）

粘贴无序实测点、设好 **X/Y 最大校准量**后点击「**一键自动校准（平移 / 小角度刚体）**」。

**模式一：仅估算全局平移**（最大旋转角留 `0`，或直接不传角度参数，与旧版完全兼容）：

1. 以每个「设计点 i − 实测点 j」的差值 `(dx,dy)=(x设计−x实测, y设计−y实测)` 作为候选全局平移（令比较坐标 实测+(dx,dy) 尽量贴合设计）；
2. **仅保留两轴均未超限者**：`|dx| ≤ 最大X校准量` 且 `|dy| ≤ 最大Y校准量`，候选按 1e-6 mm 量化去重；
3. 每个候选都复用质检的同一套**一对一匹配**（受同一最大关联半径约束），依次按
   **① 匹配对数最多 → ② 配对总残差（欧氏距离之和）最小 → ③ |dx|+|dy| 最小 → ④ dx 升序、再 dy 升序**
   确定唯一平移。

**模式二：小角度刚体校准**（最大旋转角填正数，如 `3`，并设置角度步长，如 `0.1`）：

1. 角度在 `[-最大旋转角, 最大旋转角]` 内按步长枚举（**始终包含 0° 与两侧端点**，按 1e-6 度去重），最大旋转角不得超过 15°、枚举角度数不超过 201 个；
2. 每个候选角度先把**实测点围绕板材中心**（`plateWidth/2, plateHeight/2`；未提供板材幅面时取设计点包围盒中心）做刚体旋转，再在现有 **X/Y 限幅内枚举候选平移**，即「角度 × 平移」联合搜索，候选评估总数有上限保护（20 万个）；
3. 每个（角度, 平移）候选都复用质检的同一套**一对一匹配**，依次按
   **① 匹配对数最多 → ② 配对总残差最小 → ③ 旋转角绝对值最小（能不转就不转）→ ④ |dx|+|dy| 最小 → ⑤ dx 升序、dy 升序、角度升序**
   确定唯一刚体参数；
4. 估算的**旋转角写回「校准旋转角」、平移写回 X/Y 偏移输入框并立即重跑**合格/偏移超差/缺失/多余四类判定，绿色提示条同步显示角度个数、角度×平移候选数、匹配对数、总残差与旋转中心。

注意：两种模式下缺失的设计点和多余的实测点都不参与任何候选的配对统计，因此**不会被离群点拉偏——本功能不使用质心差替代**。若搜索范围内没有任何有效候选（或参数/CSV 非法、计算量超上限），**角度与偏移输入框全部保留原值不变**，并在黄色提示条中给出明确原因（是角度范围不足、平移限幅过小还是 CSV/半径问题），不会清空或写入错误参数。

- CSV 解析错误会逐条定位到**具体物理行号（和列号）**，例如 `第 3 行：列数为 1，应为 2 列（x_mm,y_mm）`
- 叠加 SVG 用四类颜色区分：🟩 合格（绿）/ 🟧 偏移超差（橙）/ 🟥 缺失（红）/ 🟣 多余（紫）；○ 为设计点、◆ 为经刚体校准（旋转+平移）后的实测点，细线连接配对；元素上带 `data-rotation`、`data-center-x/y`、`data-measured-x/y` 属性，图内 `<desc>` 注明所用角度与中心。**拼版基准**下另以淡色虚线框画出**每个标签的边界并标注 `#n` / `⟳90°`**（0° 蓝、90° 橙），配对与缺失元素带 `data-label`、`data-label-rotation`，连线/圆/菱形均可对应到标签
- 指标：**通过率**（合格对数 / 设计点总数）、**最大偏差**、**平均偏差**（均只统计配对点），以及配对/缺失/多余计数；拼版基准下统计条还显示标签数
- **下载质检报告 CSV**：含设计点序号、**所属标签 `label_index` 与标签旋转角 `label_rotation_deg`**（单标签基准留空）、设计坐标、CSV 行号与**原始实测坐标**、**校正（旋转+平移后）坐标**、配对距离、中文结论（合格/偏移超差/缺失/多余）与**该行所用旋转角 `rotation_deg`**，并附汇总行（含 `label_count`）及参数行（含旋转角与旋转中心，UTF-8 BOM，Excel 可直接打开）；另可下载叠加 SVG

## 压印路径模式

进入「压印路径」页签后，先用左侧两个基准按钮选择**凸点输入来源**（与质检页签相互独立）：

- **单标签排版基准**：最近一次成功的单标签排版 `dots`（绿色基准条显示标签文字、凸点数与板材幅面；排版失败不会覆盖基准）；
- **最近拼版基准**：最近一次成功拼版的**顶层展平 `dots`**（保留每点 `label` / `rotation` 元数据，作业 CSV 的 `label` 列即该点所属标签）。**尚无成功拼版时该按钮禁用**；凸点数超过 2000 时基准条黄色警示且无法生成路径。

| 输入 | 含义 |
| --- | --- |
| 起点方式：压印机坐标 | 给定压印机初始位置 `(startX, startY)`（mm，缺省 0,0 = 板材左上角），为虚拟固定点、**不是凸点**；路线首段“原点→首点”的空移计入总长，2-opt 反转不得改变此前缀 |
| 起点方式：凸点序号 | `startIndex`（1 基，对应凸点在当前 `dots` 中的原序号）指定**首个压印凸点**，该点固定为步骤 1、**首步空移为 0**，其后的点序才参与反转 |

算法说明（结果对相同输入**完全确定、可重复**）：

1. **最近邻（Nearest Neighbor）**：从起点（坐标模式为虚拟原点；序号模式为指定首点）出发，每步选取未访问凸点中欧氏空移距离最小者；距离并列时依次按
   **① 标签索引升序**（单标签点无 `label`，统一记 0）**→ ② x 升序 → ③ y 升序 → ④ 凸点在输入 `dots` 中的原序号升序**
   稳定决胜；
2. **2-opt**：在最近邻路线上**最多执行 20 轮**；每轮按反转段起点下标 `i` 升序、止点下标 `j` 升序扫描，**接受首个使总空移严格缩短的反转**并立即进入下一轮；一轮内找不到严格缩短的反转即提前停止（到达局部最优）。坐标模式反转可包含“原点→首点”边，序号模式下用户指定首点永远保持在第 1 位；
3. 输出路线是输入凸点原序号的一个**排列**：每个凸点**恰好访问一次**，不重不漏。

结果与下载：

- 统计条显示凸点总数、起点信息、首/末点序号、**优化前空移总长 → 优化后空移总长（mm）、节省长度与节省比例（%）**、2-opt 实际执行轮数（最近邻已为局部最优时为 0 轮）；
- 叠加 SVG：蓝色折线为优化后路径，线段上的**小三角指示行进方向**，凸点旁蓝色数字为**步骤序号（1 基）**，绿色标记为**起点**（坐标模式为原点向上三角 + 坐标标注；序号模式为首点绿色高亮环 + `#原序号`）；元素带 `data-step / data-original-index / data-label / data-2opt-rounds / data-point-count` 等属性，拼版点保留标签标注；
- **下载作业 CSV**（UTF-8 BOM + CRLF，Excel 可直接打开）：`step,label,x_mm,y_mm,travel_mm`——`step` 为 1 基作业步骤，`label` 为拼版点所属标签（单标签基准留空），`x_mm/y_mm` 为该步压印坐标，`travel_mm` 为**从上个位置到本步的空移距离**（序号模式首步为 0）；另可下载路径 SVG。
- **错误语义**：凸点超过 **2000** 个、`dots` 缺失/含非法坐标、起点序号越界或非整数、两种起点方式同时指定、坐标非数字等情况下返回 `ok=false`，错误信息明确，且 `steps/order` 为空、`csv/svg` 为 `null`——**绝不输出部分路径**。

## API

### `POST /api/layout`

```json
{ "text": "EXIT Door 2", "plateWidth": 100, "plateHeight": 50, "dotSpacing": 2.5, "lineSpacing": 10, "margin": 5 }
```

返回 `{ ok, errors, params, cellsPerLine, maxLines, lines, dots, brailleText, stats, svg }`：

- `ok=false` 时 `errors` 列出放不下的具体原因，`svg/dots` 为空（不输出裁切结果）
- `dots[].x/y/r` 为每个凸点的毫米坐标，`svg` 为完整 SVG 文档（`width/height` 以 mm 标注）

### `POST /api/panel`

多标签拼版。`labels` 为字符串（每行一条）或字符串数组；其余为所有标签共享的板材/点距/行距/边距/标签间距参数：

```json
{
  "labels": "EXIT\nWOMEN\nMEN",
  "plateWidth": 120, "plateHeight": 80,
  "dotSpacing": 2.5, "lineSpacing": 10,
  "margin": 5, "labelGap": 5
}
```

返回 `{ ok, errors, mode:"panel", params, labelCount, skippedBlank, labels[], dots[], stats, svg }`：

- `ok=true` 时：
  - `labels[]` 逐条为 `{ index, sourceLine, text, brailleText, cells, rotation(0|90), x, y, localWidth, localHeight, placedWidth, placedHeight, bounds:{x,y,width,height}, dots[] }`；`x/y` 为标签局部原点锚点（90° 时在包围盒右上角），`bounds` 为板材上的包围矩形；
  - 顶层 `dots[]` 是所有标签凸点的展平数组，元素为单标签点结构 `{x,y,r,line,cell,dot}` 加上 `{label, rotation, localX, localY}`，可直接传给 `/api/qc`；
  - `stats` 含 `labelCount / skippedBlank / rotatedCount / totalCells / totalDots / packWidth / packHeight / labelArea / remainingArea / usableWidth / usableHeight`；
  - `svg` 为整板 SVG：每个标签一个 `<g data-label-index data-rotation>`，内含边界矩形、`<title>`（索引+原文+角度）与 `translate(...) [rotate(90)]` 后的凸点。
- `ok=false` 时 `labels/dots` 为空数组、`svg=null`，`errors[]` **逐条**列出问题标签（带 `labelIndex`；类型为 `label-unsupported-char / label-too-long / label-too-wide / label-pack-fail` 或参数错误），不输出任何部分版面。

### `POST /api/qc`

```json
{
  "design": [{ "x": 5, "y": 5, "r": 0.75 }],
  "csv": "x_mm,y_mm\n5.2,4.9",
  "offsetX": 0, "offsetY": 0, "rotation": 0,
  "tolerance": 0.5, "maxRadius": 2,
  "plateWidth": 100, "plateHeight": 50
}
```

返回 `{ ok, errors, params, baseline, transform, measuredCount, pairs, missing, extra, stats, svg, csv }`：

- `ok=false` 时 `errors[]` 含参数错误与逐行（`line` 列）CSV 解析错误，`svg/csv` 为空
- `params.rotation` 为本次质检使用的旋转角（度，缺省请求字段时为 `0`）；`transform.centerX/centerY` 为旋转中心（板材中心，缺幅面时为设计点包围盒中心）
- `pairs[]` 含双方坐标、**原始实测坐标** `measuredX/Y`、**校正坐标** `correctedX/Y`、距离与 `verdict`（`pass` / `offset`）；`missing[]`、`extra[]` 为未配项
- `baseline` 含 `count` 与板材幅面；传入拼版顶层 `dots` 时另含 **`labelCount` 与 `labels[]{index,rotation,dotCount}`**（各标签索引/旋转角），`pairs[]` 与 `missing[]` 的每项带 **`label`（标签 1 基索引）与 `labelRotation`（标签拼版旋转角 0/90）**；单标签基准下 `labelCount=0`、这两个字段为 `null`
- `stats` 含 `passRatePercent`、`maxDeviation`、`meanDeviation` 等；叠加 SVG 在拼版基准下额外绘制标签边界（`data-label-count`、`class="qc-label" data-label-index data-rotation`、点元素 `data-label/data-label-rotation`）；`csv` 为可直接下载的报告文本（明细含 `label_index,label_rotation_deg`，末列 `rotation_deg` 为质检校准角，参数行含旋转角与旋转中心）。请求参数与旧版完全一致——拼版点只是带有额外字段的 `{x,y,r,...}` 超集

### `POST /api/qc/calibrate`

纯平移（旧调用，不传任何角度字段，完全向后兼容）：

```json
{
  "design": [{ "x": 5, "y": 5, "r": 0.75 }],
  "csv": "5.4,5.25",
  "maxOffsetX": 2, "maxOffsetY": 2,
  "maxRadius": 2
}
```

小角度刚体校准（新增 `maxAngle` / `angleStep`，均为度；另建议传板材幅面以确定旋转中心）：

```json
{
  "design": [{ "x": 20, "y": 15 }],
  "csv": "20.1,14.8",
  "maxOffsetX": 2, "maxOffsetY": 2,
  "maxRadius": 2,
  "maxAngle": 3, "angleStep": 0.1,
  "plateWidth": 100, "plateHeight": 50
}
```

自动校准：纯平移模式枚举「设计点－实测点」候选平移并限幅去重；刚体模式在 `±maxAngle` 内按步长枚举角度（含 0°），实测点围绕板材中心旋转后再枚举限幅内平移。每个候选复用一对一匹配，按匹配数 → 总残差 →（刚体模式）旋转绝对值 → |dx|+|dy| → dx/dy/角度升序决出唯一结果。

返回 `{ ok, errors, offsetX, offsetY, rotation, centerX, centerY, matchedCount, totalResidual, designCount, measuredCount, candidateCount, rigidMode, angleCount }`：

- `ok=true` 时 `offsetX/offsetY` 为建议写回偏移框的平移（mm，4 位小数），`rotation` 为旋转角（纯平移模式恒为 `0`），`centerX/centerY` 为旋转中心；`matchedCount` 为该参数下的匹配对数，`totalResidual` 为配对总残差，`candidateCount` 为限幅去重后的候选数（刚体模式为各角度候选总数），`rigidMode` 标识是否启用了角度搜索，`angleCount` 为枚举角度数（纯平移模式为 `null`）；
- `ok=false`（无可用候选、参数/CSV 错误、点数或计算量超上限）时 `offsetX/offsetY/rotation` 均为 `null`，`errors[]` 给出明确原因，调用方应保留角度与偏移输入框原值。只传 `maxAngle` 与 `angleStep` 其中之一会被视为参数错误（不会静默退化为纯平移）。

### `POST /api/path`

压印路径：输入最近一次成功排版/拼版的 `dots`（单标签 `{x,y,r,...}` 或拼版顶层展平点，后者带 `label/rotation`），从用户指定起点出发生成逐点作业顺序。起点二选一：

- **坐标模式**：`startX/startY`（mm，均缺省 = `(0,0)`；只传其一则另一个按 0），为压印机虚拟起点；
- **序号模式**：`startIndex`（1 基原序号），该凸点固定为步骤 1、首步空移 0。

```json
{
  "dots": [{ "x": 5, "y": 5 }, { "x": 11, "y": 5 }],
  "startX": 0, "startY": 0,
  "plateWidth": 100, "plateHeight": 50
}
```

返回 `{ ok, errors, params, steps[], order[], nnOrder[], stats, svg, csv }`：

- `ok=true` 时：
  - `steps[]` 逐项为 `{ step, originalIndex, x, y, label, labelRotation, travelMm }`（`travelMm` 为从上个位置到本步的空移，序号模式首步为 0；单标签点 `label=null`）；
  - `order[]` 为优化后访问顺序（凸点原序号 1 基排列），`nnOrder[]` 为优化前最近邻顺序；
  - `stats` 含 `pointCount / beforeTotalMm / afterTotalMm / savedMm / savedPercent / roundsUsed / maxRounds(=20) / improved / firstStep / lastStep`；
  - `svg` 为带步骤序号与行进方向的路径叠加图，`csv` 为 `step,label,x_mm,y_mm,travel_mm` 作业文本（UTF-8 BOM）；
- `ok=false`（凸点超过 **2000**、坐标非法、`startIndex` 越界/非整数、两种起点同时指定、起点坐标非数字等）时 `steps/order` 为空数组、`csv/svg=null`，`errors[]` 给出明确原因，**不输出任何部分路径**。

健康检查：`GET /api/health`

## 项目结构

```
├── server.js            # Express 服务：静态页面 + /api/layout + /api/panel + /api/qc + /api/qc/calibrate + /api/path
├── lib/braille.js       # 核心：一级盲文转换、整词换行排版、毫米坐标 SVG 生成
├── lib/panel.js         # 核心：多标签解析、单行矩形复用、0/90° 行级装箱（剩余面积最小稳定择优）、整板 SVG/JSON
├── lib/qc.js            # 核心：实测 CSV 解析（行号定位）、一对一最优匹配、判定/SVG/CSV 报告、自动校准（纯平移 + 小角度刚体）
├── lib/path.js          # 核心：压印路径最近邻 + 最多 20 轮 2-opt（同距离稳定决胜）、统计/带序号方向 SVG/作业 CSV
├── public/              # 原生前端（index.html / app.js / style.css，四个页签）
├── test/                # node:test 单元/接口测试（排版 + 拼版 + 质检 + 压印路径 + HTTP API）
├── Dockerfile           # 单阶段构建，npm install + 启动
└── docker-compose.yml   # 一条命令编排启动
```
